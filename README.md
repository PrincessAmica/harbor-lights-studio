# Harbor Lights Studio website

Public website for Anchor:
https://harborlightsstudio.ch

## Pages
- index.html — Homepage
- privacy.html — Privacy notice and Impressum
- delete-account.html — Account deletion instructions
- impressum.html — Redirect to the Impressum
- site-language.js — English, German and French translations
- CNAME — Custom domain configuration; keep this file

## Publishing
Upload the website files to the repository root and commit to main.
GitHub Pages publishes the changes automatically.

## Languages
The website initially uses a supported browser language, otherwise English.
Manual language choices are remembered in the browser.
When changing text, update all three translations in site-language.js
and the English fallback text in the relevant HTML page.

## Privacy
No visitor analytics or advertising scripts are added.
The selected language is stored locally in the visitor’s browser.
Hosting providers may process technical logs as described in the privacy notice.

## Maintenance
Keep contact details, privacy information and account deletion
instructions consistent with the app’s actual behaviour.
